# Colour Pattern 🌈 — Interactive Color Pattern Generator

A free, no-login, client-side interactive color pattern generator. Pick colors and watch beautiful patterns render in real time — great for design inspiration, wallpapers, and learning color theory.

## Features

- **Interactive pattern canvas** — patterns generated and animated live in the browser
- **Color pickers** — choose your own palette for the patterns
- **Pattern controls** — size, density, and style parameters
- **Instant preview** — every change renders immediately
- **Fully client-side** — single HTML file, no backend, no sign-up, works offline
- **Responsive layout** — works on desktop and mobile

## Tech Stack

- Plain HTML5 / CSS3 / JavaScript (single-file app, zero build step)
- Canvas-based pattern rendering
- No dependencies, no frameworks

## Quick Start

Open `index.html` in any modern browser — that's it. Or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
